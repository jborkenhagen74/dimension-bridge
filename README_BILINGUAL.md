# DimensionBridge Documentation / Dokumentation

Complete documentation is available in two languages:

- [Deutsch – Installation, Konfiguration, Befehle und Beispiele](INSTALLATION_DE.md)
- [English – Installation, configuration, commands and examples](INSTALLATION_EN.md)

The documentation covers:

- Velocity and Fabric installation;
- supported Minecraft and Java versions;
- all configuration properties;
- permissions and security;
- Fabric and Velocity commands;
- telephone-booth and return-portal examples;
- particle shimmer, countdown and clickable chat-menu examples;
- troubleshooting and update instructions;
- Modrinth and CurseForge packaging notes.
